# Healthcare-SLA-Analytics
Healthcare ticket analysis using Python, Pandas, and Power BI to evaluate SLA compliance, escalations, and support performance.

## Project Overview
This project focuses on analyzing healthcare support ticket data to evaluate Service Level Agreement (SLA) performance, ticket resolution, escalations, and customer satisfaction. The goal is to identify operational bottlenecks and present meaningful insights through an interactive Power BI dashboard.

## Objectives
- Analyze SLA compliance and SLA breach rates.
- Evaluate ticket resolution and escalation patterns.
- Explore potential reasons for SLA breaches.
- Monitor key performance indicators (KPIs).
- Present findings through an interactive dashboard.

## Tools & Technologies
- **Python** – Data analysis and processing
- **Pandas** – Data cleaning and manipulation
- **Power BI** – Dashboard development and data visualization
- **CSV** – Dataset format

## Project Workflow
1. **Data Inspection:** Loaded and inspected the raw healthcare ticket dataset.
2. **Data Preparation:** Examined the data and prepared it for analysis using Python and Pandas.
3. **Exploratory Data Analysis:** Examined ticket volumes, SLA breaches, escalations, and customer satisfaction.
4. **KPI Analysis:** Evaluated SLA breach rates and ticket performance across relevant categories.
5. **Dashboard Development:** Created a Power BI dashboard to visualize ticket metrics and operational performance.

## Key Areas of Analysis
- SLA Breach Rate
- Ticket Volume
- Ticket Priority
- Escalation Status
- Potential Root Causes of SLA Breaches

## Key Observations
The analysis explored potential operational issues, including missing information, process delays, and manual processing, that may contribute to SLA breaches.
